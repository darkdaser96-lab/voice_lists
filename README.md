# voice_lists

Telegram-бот голосовых и текстовых заметок по спискам. Вебхук на Vercel: голос → Groq Whisper, команды → Groq chat (JSON), данные списков хранятся в памяти процесса и могут исчезнуть после cold start.

## Возможности

- Добавление, показ, удаление последней или одной заметки, очистка списка.
- Переименование списков, избранное (★), порядок списков внутри групп.
- Пунктуация заметок исправляется моделью без изменения смысла.
- Голосовые сообщения расшифровываются Groq Whisper.

## URL

- Лендинг: https://voice-lists-ten.vercel.app

## Переменные окружения

`TELEGRAM_BOT_TOKEN`, `GROQ_API_KEY`, `WEBHOOK_URL` (опционально). Ключи не хранятся в Git.
