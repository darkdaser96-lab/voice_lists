# voice_lists

Telegram-бот голосовых и текстовых заметок по спискам. Вебхук на Vercel: голос → Groq Whisper, команды → Groq chat (один JSON), списки в RAM на `chat_id` (после cold start могут пропасть).

## Что умеет

- **Список по умолчанию — «Стикеры»**; при показе заметки — inline-кнопки (1–4 в столбец, 5+ по две в ряд).
- **Добавить / показать / новый список** — голос или текст («в покупки молоко», «покажи покупки»).
- **Удалить** — одну заметку (номер, кусок текста), последнюю, или очистить весь список по явной фразе.
- **Переименовать** — «переименуй покупки в дела»; если имя занято или старого нет — отказ без затирания.
- **Избранное** — «покупки в избранное» / «убери звезду с покупок»; на кнопке и в «покажи» префикс ★.
- **Поднять список** — «подними покупки»; избранные сверху, внутри группы ручной порядок.
- **Пунктуация** — в `note` модель правит знаки, смысл и слова не выдумывает.

Клавиатура: «Новая заметка», «Удалить заметку», затем списки (★ у избранных). Отмена: `/cancel`.
